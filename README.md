# Control Parental Módem Telmex (Huawei HG8141X7b-50)

Aplicación móvil nativa para Android diseñada para pausar y reanudar el acceso a internet de los dispositivos seleccionados (hijos/tablets) en tu red local de Telmex.

---

## 🚀 Cómo compilar y obtener tu archivo .APK en 3 pasos (Sin instalar nada)

Este proyecto incluye **GitHub Actions**, por lo que GitHub compilará el archivo `.apk` de forma gratuita en la nube:

### 1. Crear un repositorio en GitHub
1. Entra a [github.com](https://github.com/) e inicia sesión con tu cuenta (o crea una gratis si no tienes).
2. Haz clic en el botón verde **"New"** (o **Nuevo repositorio**).
3. Nómbralo: `ControlParentalTelmex`.
4. Elige si quieres que sea **Público** o **Privado** (ambos funcionan) y haz clic en **"Create repository"**.

### 2. Subir los archivos del proyecto
En la página del repositorio recién creado:
1. Haz clic en **"uploading an existing file"** (subir archivos existentes).
2. Arrastra y suelta todos los archivos y carpetas que están dentro de:
   `c:\Users\Edgar\OneDrive\Edgar\ANTIGRAVITY\ControlParentalTelmex`
   *(Asegúrate de incluir la carpeta `.github`)*.
3. Haz clic en el botón verde **"Commit changes"**.

### 3. Descargar el APK listo a tu celular
1. Ve a la pestaña **Actions** en la parte superior de tu repositorio en GitHub.
2. Verás que se inició automáticamente un flujo llamado **"Compilar APK Control Parental Telmex"**.
3. Tardará aproximadamente **2 a 3 minutos** en compilar. Cuando termine (aparezca con una palomita verde ✔️), haz clic en él.
4. En la parte inferior, en la sección **Artifacts**, verás el archivo:
   👉 **`ControlParental-Telmex-APK`**
5. Descárgalo directamente desde tu celular (o pásalo por WhatsApp/Telegram/Cable), ábrelo e instálalo.

## 📱 Cómo usar la Aplicación

1. **Conéctate al Wi-Fi de tu casa** (el módem Telmex).
2. Abre la app en tu celular.
3. La primera vez te pedirá ingresar la **Contraseña WPA de tu módem** (la misma que viene en la etiqueta trasera).
4. **Listo:**
   - Presiona **PAUSAR INTERNET** para cortar el acceso a los dispositivos que tengas en la lista negra de tu módem.
   - Presiona **REANUDAR INTERNET** para devolverles la conexión.
   - O usa los botones rápidos: **⏱ 30 min**, **⏱ 1 hora**, **⏱ 2 horas** para una pausa temporal que se reactiva sola automáticamente.
